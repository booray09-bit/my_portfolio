# M. Taimour — Student Portfolio

A simple, responsive student portfolio website built using HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- About section
- Skills section
- Project cards
- Contact/GitHub link

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`.
5. Click Save and wait for deployment.

## Personalize before submission
